# LBR 3-10 Oscillator for MetaTrader 5

A custom indicator for MetaTrader 5 implementing the **LBR 3-10 Oscillator** by Linda Bradford Raschke.

## What is it?

The LBR 3-10 Oscillator is a momentum indicator similar to MACD. It measures the difference between a short-term moving average and a medium-term moving average, then smooths the result to produce a signal line.

Default settings follow Linda Raschke's original specification:

- **Fast MA:** 3 periods
- **Slow MA:** 10 periods
- **Signal line:** 16-period smoothing of the oscillator

This implementation is adapted from the Pine Script version by **bonfireAlgorithm**.

## Features

- Switchable MA type for oscillator: SMA or EMA
- Switchable MA type for signal line: SMA or EMA
- Histogram drawn as the MACD line itself (matching the original Pine Script behavior)
- Optional volatility normalization using ATR
- Optional standard deviation bands
- Input validation to prevent invalid settings

## Requirements

- MetaTrader 5 build 1930 or later
- MetaEditor 5 (included with MetaTrader 5)

## Installation

1. Clone or download this repository.
2. Copy `LBR_3_10_Oscillator.mq5` to your MetaTrader 5 indicators folder:

   ```
   %APPDATA%\MetaQuotes\Terminal\<InstanceID>\MQL5\Indicators\
   ```

   Replace `<InstanceID>` with your terminal's data folder hash.

   > Tip: In MetaTrader 5, go to **File → Open Data Folder** to find the exact path.

## Building

### Option 1: MetaEditor

1. Open **MetaEditor 5**.
2. Go to **File → Open** and select `LBR_3_10_Oscillator.mq5`.
3. Press **F7** or click **Compile**.
4. If compilation succeeds, the file `LBR_3_10_Oscillator.ex5` will appear in the same folder.

### Option 2: MetaTrader 5 Terminal

1. Copy the `.mq5` file to the `MQL5\Indicators` folder.
2. In MetaTrader 5, go to **Navigator → Indicators**.
3. Right-click `LBR_3_10_Oscillator` and select **Modify** to open it in MetaEditor.
4. Press **F7** to compile.

## Running

1. In MetaTrader 5, open the **Navigator** panel (`Ctrl+N`).
2. Expand **Indicators → Custom**.
3. Drag `LBR_3_10_Oscillator` onto the chart you want to analyze.
4. Adjust parameters in the settings dialog if needed, then click **OK**.

The indicator will appear in a separate sub-window below the price chart.

## Parameters

| Parameter | Default | Description |
|-----------|---------|-------------|
| `Fast Length` | 3 | Period of the fast moving average |
| `Slow Length` | 10 | Period of the slow moving average |
| `Source` | Close | Price source for the moving averages |
| `Signal Smoothing` | 16 | Period of the signal line |
| `Simple MA(Oscillator)` | true | Use SMA for the oscillator; set to false to use EMA |
| `Simple MA(Signal Line)` | true | Use SMA for the signal line; set to false to use EMA |
| `Show std. bands` | false | Show optional standard deviation bands |
| `St. dev.` | 1.5 | Multiplier for the standard deviation bands |
| `St. dev. length` | 100 | Lookback period for the standard deviation calculation |
| `Volatility normalized` | false | Normalize the oscillator by ATR(10) multiplied by 100 |

## How to read it

- **MACD Line / Histogram:** Difference between the fast and slow moving averages.
- **Signal Line:** Smoothed version of the MACD line.
- **Zero line:** Values above zero suggest bullish momentum; values below zero suggest bearish momentum.
- **Divergences:** When price makes a new extreme but the oscillator does not, it may signal a potential reversal.
